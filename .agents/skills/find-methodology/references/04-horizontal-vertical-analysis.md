# 横纵分析法

## 适用问题与输入

用于理解一个对象如何演变，以及它与同类对象有何差异。输入包括研究对象、分析用途、时间范围、已有材料和可比较的对象。

## 核心动作

1. 明确问题和时间范围；涉及当前情况时核实资料时效，同时区分事件时间和资料发布日期。
2. 纵向梳理诞生背景、需求、推动者、关键转折、成功与失败，解释早期选择形成的能力、路径依赖和约束。
3. 横向选择与当前问题相关的比较对象，说明选择理由，采用含义、时间和口径一致的维度比较。
4. 将两条轴连接起来，解释当前差异怎样形成，以及用户或市场选择背后的机制。
5. 任务需要未来判断时，提出有条件的演变路径，并说明成立前提和可观察信号。

重要结论优先依据原始资料和可核查数据，就近标注来源与日期。区分事实、推断和观点；冲突材料保留各自依据与适用范围，资料缺口具体说明。

## 独立使用

根据问题交付结论、关键时间线、对比表和解释；未来判断按任务需要展开。报告篇幅服从信息量和用户要求。

## 嵌入工作流

为调研、产品分析或技术选型提供分析结构。复用当前流程已核实的材料，将时间线、比较维度和解释交回其报告或决策步骤；发现资料缺口时交由当前取证流程补查。

## 产出与完成条件

产出有来源的演变脉络、可比的差异和解释。主要判断已回应研究问题、关键不确定性已说明时完成。
