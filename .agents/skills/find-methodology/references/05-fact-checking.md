# 事实核查

## 适用问题与输入

用于检查说法、数据、结论或方案的事实基础和推理。输入包括原始说法、上下文、现有来源，以及该判断将用于什么决定。

## 核心动作

1. 拆分可验证的事实、从事实推出的结论，以及其中的价值判断。
2. 按具体事实核查原始来源、样本、时间、口径和完整上下文；已有可靠且适时的核验结果可以复用，需要外部证据时查证。
3. 依据证据将事实判断为已证实、需收窄、存在争议、证据不足或错误，并说明理由。
4. 检查事实是否支持结论、是否依赖未验证的假设、是否混淆相关与因果，以及是否存在替代解释。
5. 给出与证据强度相称的修正版，说明结论成立和失效的条件。价值取舍保留其目标与偏好依据。

## 独立使用

交付事实核验结果、关键推理缺口、补强后的表述和当前可采用的判断。证据状态随具体材料说明。

## 嵌入工作流

复用当前调研或专业流程已核实的事实，重点处理尚未覆盖的论证和假设。将修正内容及其影响交回原结论、方案或报告。

## 产出与完成条件

产出可信事实、待核事项、推理缺口与结论边界。影响当前决定的关键主张已有证据判断，剩余缺口及其影响明确时完成。
