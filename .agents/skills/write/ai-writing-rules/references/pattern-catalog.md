# Quality Model And Gap Catalog

审计比较“当前文本”与“目标文本”。单个词、标点或句式只提供线索；模式组合、密度、上下文和实际影响决定优先级。

## P0：完整性与语义

目标文本满足以下条件：

- 数字、案例、引文、来源、用户反馈、实验结果和执行状态均有输入依据；
- 可能、推测、计划、已验证和已完成保持各自状态；
- 主体、条件、范围、因果、证据强度及法律与技术含义保持稳定；
- 材料冲突、未知项和待确认项获得显式标记；
- 引用、脚注、占位符和交付状态真实有效。

偏离这些目标的内容记为 P0，事实完整性优先于风格优化。

## P1：清晰度与信息价值

### 命题质量

- **证据连接**：评价和结论连接来源、机制、状态或明确判断。
- **状态准确**：计划、能力、结果和远期影响分别陈述。
- **具体职责**：功能描述包含主体、动作、对象和条件。
- **信息推进**：段落新增证据、区分、因果、约束、选择或后果。
- **真实归因**：行业观点、研究结论和用户反馈指向可核验来源。
- **适度意义**：贡献大小与材料证据相称。

### 句子与段落

- **直接定义**：类别、职责和机制直接出现。
- **真实边界**：范围、责任和限制写成可执行条件。
- **稳定术语**：同一概念使用同一名称。
- **清晰关系**：连接词、列表和符号对应真实逻辑关系。
- **自然节奏**：句长和段落长度随内容变化。
- **有效元话语**：开场、转折和总结承担导航或论证作用。

### 版式

- 标题层级对应内容层级；
- 列表项保持语法平行和逻辑同类；
- 表格用于比较、映射和验收；
- 加粗、冒号、破折号、括号和引号服务扫描与语义；
- 摘要、正文和结尾各自增加适合其位置的信息。

## P2：语境校准

以下形式由领域用途决定：

- 被动语态可突出研究对象、义务对象或未知主体；
- 谨慎语气可表达证据限制；
- 列表和表格可承载规格、规则与验收条件；
- 第一人称可承载复盘、评论、邮件与个人声线；
- 重复术语可维护技术和法律一致性；
- 冒号、破折号和短段落可组织节奏；
- 专业术语、公式、符号和路径遵循目标读者与领域契约。

P2 只在形式损害目标读者的理解或破坏上下文时进入修改范围。

## 肯定性表达检查

为每个句子识别其核心任务：定义、功能、边界、约束、评价或论证。

| 任务 | 目标结构 |
|---|---|
| 定义 | 对象 + 类别或本质属性 |
| 功能 | 主体 + 动作 + 对象 + 结果 |
| 边界 | 适用范围 + 责任主体 + 条件 |
| 约束 | 触发条件 + 允许动作 + 处理方式 |
| 评价 | 判断 + 证据或机制 + 适用条件 |
| 论证 | 主张 + 证据 + 推理 + 限定 |

否定承担范围排除、法律义务、证据限制、概念辨析、既有误解纠正或真实观点回应时，它就是目标命题的一部分。其他否定对照直接改写为对应的目标结构。

示例：

- 原文：`这不是一次简单升级，而是一场能力体系的全面重塑。`
- 目标：`本次升级新增权限隔离、失败重试和审计日志。`

- 原文：`你的产出是建议，不是裁决：不标严重程度，不做通过判定。`
- 目标：`你的产出包括事实核对结果和具体修改建议；项目负责人作出最终验收结论。`

- 语义性否定：`本阶段不迁移历史附件，只迁移结构化记录。`
- 保留理由：该句定义迁移范围。

## 审计方法

1. 写出该段的目标命题。
2. 标出主体、动作、对象、证据、条件和状态。
3. 识别目标命题与当前文本之间的差距。
4. 判断差距对事实、理解、决策或声线的影响。
5. 给出完整目标表达，供编辑阶段覆盖原语义单元。
