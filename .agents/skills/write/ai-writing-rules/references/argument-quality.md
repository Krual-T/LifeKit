# Argument Quality

评论、博客、研究综合、复盘和分析材料需要形成判断时使用本页。目标是让每段推进问题，并让结论承担清晰的证据责任。

## 判断边界

从用户材料中确定：

- 文本回答的问题；
- 当前证据支持的判断及支持强度；
- 材料之间的冲突；
- 作者承担的结论、保留意见和未决问题；
- 可披露的亲历细节、观察或案例。

缺失信息作为问题或显式假设。作者经历、情绪、动机、异议和立场只来自用户材料。

## 论证单元

每个重要段落由任务需要选择以下组成部分：

1. **主张**：本段推进的判断；
2. **证据**：来源、数据、观察或案例；
3. **推理**：证据支持主张的机制或比较标准；
4. **限定**：适用条件、证据强度和未知项；
5. **后果**：该判断对决策或下一步的影响。

## 关键质量目标

### 持续推进

每段增加证据、区分、因果、约束、选择或后果。相邻段落围绕同一判断时，合成为一个完整论证单元。

### 明确裁决标准

并列观点使用统一标准比较，说明证据权重、适用条件和作者结论。当前证据只能支持暂缓判断时，写明所需证据和暂缓原因。

### 保留真实冲突

来源分歧按双方主张、证据和适用边界展开。综合结论说明它成立的条件与付出的取舍。

### 证据化具体

数字、场景、人物反应和个人经验来自输入材料。材料粒度有限时，通过明确对象、动作、条件和未知项提高具体性。

### 展示推理责任

重要结论呈现证据链、替代解释、适用条件和可能失效的环节。真实分岔来自材料本身。

## 编辑流程

1. 为每段标注新增的信息或判断。
2. 找出需要比较、裁决或保留的真实分歧。
3. 将判断连接到证据、比较标准和适用条件。
4. 用完整论证单元覆盖模板化总结和抽象平衡。
5. 复核作者立场、来源事实和分析判断的边界。

## 完成标准

- 每段对问题形成可指出的推进；
- 重要判断能回到证据、比较标准或明确经验；
- 冲突与不确定性获得准确表达；
- 作者立场和经验具有输入依据；
- 节奏、转折和声线服务论证。
