# 我的复盘约定

初始化时复制为本 Skill 的 `AGENTS.md`，按自己需要改写。以下是可删改的默认选择。

## 想从复盘中得到什么

帮助我恢复经历，看清实际变化与自己的选择，保留值得以后回想的内容。工作、学习、生活、感受和灵感都可以进入复盘。

## 如何交流与成稿

- 开始时先给简短概览，有值得讨论的内容再展开。
- 默认先聊后写；我直接要求报告时直接整理。未明确说过的感受、动机和决定保持未知。
- 正文按内容组织，篇幅以讲清楚为准。不要求每次都有问题、行动项或固定栏目。
- 周、月、年可以直接读取该时期的信源；已有复盘用于定位和理解变化。
- 可参考 [写法示例](references/review-guide.md)，按本次需要调整。

## 来源与日期

使用本 Skill 的 `Registry.md` 中已启用的来源，并按本次主题选择相关材料。新增来源时先明确允许的账号、项目、文件或会话范围。

日期默认按我的当前时区理解自然日、自然周、自然月和自然年。有固定日边界或其他周期口径时，在这里写明。

## 保存

需要保存时，报告与续聊草稿放在项目 `wiki/reviews/`，按周期和日期命名；也可以在这里改成自己的目录。草稿记录来源、已聊内容与需要接续的位置。使用 Wiki 时遵循 Using Wiki 的文档与索引规则。

临时导出用 `.env` 中的路径，缺省 `tmp/periodic-review/`。原件按需留存；未配置对象存储时直接使用已有阅读入口或本地文件。

## 通知与定时

默认仅在当前对话展示结果。需要通知时，在这里写清渠道、本人收件身份、何时发送、允许的内容和重复通知规则；安装工具或登记材料来源不构成发送授权。

定时调用可从 README 复制提示词。触发时间在使用者自己的定时器中设置。
