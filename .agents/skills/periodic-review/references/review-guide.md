# 复盘写法示例

以下内容供实例 AGENTS 选择或改写。报告可以是短文、主题记录或事实与理解分开的两份文档；按用户目标决定。

| 回看尺度 | 可关注的内容 |
| --- | --- |
| 日 | 今天的经历、变化、选择、感受，以及值得记住的片段 |
| 周 | 几天之间如何推进、哪些认识发生改变、反复出现的体验 |
| 月 | 多条主线的变化、重要取舍、持续问题与已经形成的经验 |
| 年 | 长期轨迹、转折、关系与生活变化、以后仍有参考价值的理解 |

一种简单写法是先说明时期和材料范围，再按重要主题讲清发生了什么、现在怎么看。来源链接放在相关事实附近。确有本人决定的后续行动时保留；没有行动项也可以结束。

资料量大时，先按时间或主题读原文并做带来源的短记录，再综合理解。已有日记、日报、月报可以帮助定位；直接读取目标时期的来源同样可行。缺少某份下级报告不妨碍回顾已有材料。

本人感受按本人陈述保存。助手可提出有依据的理解，同时保留未确认的部分；不把建议当作本人决定，不从消息数量推断投入或从沉默推断已经结束。

需要续聊时保存简短草稿，写明时期、已读来源、本人补充和下次可以接续的位置。保存前检查引用与归因，按实例采用的文档规范完成。
