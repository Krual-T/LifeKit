# 笔记与文档

这类信源可以只有阅读说明。无需安装本目录的脚本，也无需把原文复制到复盘仓库。

在 Skill 的 `Registry.md` 写清楚：可读的目录或文档链接、日期依据、范围限制，以及使用哪个已授权工具打开它。例如：

| 来源 | 允许范围 | 阅读方式 |
| --- | --- | --- |
| 个人笔记 | `notes/` 下正文日期落在本周期的 Markdown | 先列目录，再读命中的原文；引用路径和日期 |
| 项目文档 | 已登记的文档链接及其指定章节 | 用该平台的官方工具读取；保留链接和阅读时可见的版本信息 |
| 既有复盘 | 已登记的复盘目录 | 直接读覆盖本周期的报告，需要时沿其引用补读原文 |

周期以本次请求和 Skill 的 `AGENTS.md` 为准。文件修改时间只能帮助找候选，不能代替正文中的事件日期；在线文档当前版本也不能自动证明过去某天写了什么。

PDF、Word 等文件按已安装的文档阅读 Skill 处理。登录、文件权限和解析失败照实报告；没有可读正文时保留入口和缺口，不根据标题补造内容。

日记、感受、想法和本人补充都可以成为材料，不要求存在任务、产出或行动项。
