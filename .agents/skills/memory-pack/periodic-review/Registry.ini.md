# 我的复盘信源

初始化时复制为本 Skill 的 `Registry.md`。这是给 Agent 阅读的登记表，可以按需要改成分节描述。每个来源写清使用状态、定位、允许范围和阅读办法。

示例均未启用；按实际情况替换占位路径，删除不用的条目。

| 来源标识 | 使用状态 | 阅读说明 | 允许范围与定位 |
| --- | --- | --- | --- |
| personal-notes | 未启用 | [本地笔记与在线文档](sources/notes/README.md) | 填写允许读取的目录或文档链接、必要时间字段 |
| project-dialogue | 未启用 | [Codex 对话](sources/codex/README.md) | 填写项目目录、会话存放位置、需要包含或排除的线程 |
| project-git | 未启用 | [Git 记录](sources/git/README.md) | 填写仓库目录、主机和需要关注的变更范围 |
| work-feishu | 未启用 | [飞书](sources/feishu/README.md) | 填写账号选择办法、允许的群/文档/任务等类别与具体范围 |

同一种阅读方式可以登记多个来源，例如两个项目各有一个标识。阅读需要参数文件时，在此链接到该信源目录里的实例配置，避免重复维护账号和路径。凭据由对应工具管理，登记表只保存定位和非秘密配置。

新来源可以是一份阅读说明或现有工具入口，不要求新增脚本。比如登记“读指定日历中这一周的事件”，写清账号、日历和读取方法即可。

材料链接可能变化，记录其当时可见范围；只有实际读取过，才能说明已覆盖。没有访问条件时保留缺口，不用空列表表示成功。
