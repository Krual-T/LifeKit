# Audit And Edit Contracts

## Detect Contract

报告足以影响质量的目标差距，同一根因合并，按风险排序。

| 字段 | 要求 |
|---|---|
| Priority | `P0`、`P1` 或 `P2` |
| Location | 标题、段落、句子或行号 |
| Evidence | 最短必要原文片段 |
| Target | 目标质量或目标命题 |
| Gap | 当前表达与目标之间的差距 |
| Impact | 对事实、清晰度、声线或读者决策的影响 |
| Context | 领域功能、证据限制或判断条件 |
| Target expression | 完整目标句或目标结构 |

文本达到目标时，报告“当前文本符合质量目标”，并列出仍待核验的事实或来源。

## Edit Contract

输出通常包括：

1. 重写后的正文；
2. 关键变更及其根因；
3. 保持稳定的术语、事实、引文、代码和声线特征；
4. 二次审计结果与待确认内容。

用户只需要正文时，内部仍完成二次审计。

## Target-State Rewrite

每个命中按以下顺序处理：

1. 确定该语义单元需要完成的任务；
2. 从输入材料提取事实、判断、责任、条件和证据；
3. 选择定义、功能、边界、约束、评价或论证的目标结构；
4. 重写完整句子、段落、列表或表格；
5. 用目标版本覆盖原有逻辑；
6. 检查前后衔接和全文一致性。

局部拼接适合修正独立的错字、标点和格式。事实模型、论证结构、责任边界、抽象层级或声线出现偏差时，完整语义单元重写是默认方式。

## Second-Pass Audit

- 每个事实和因果都有输入依据；
- 证据强度与结论动词匹配；
- 条件、例外、责任主体和适用范围完整；
- 引文、代码、技术标识符和法律用语保持稳定；
- 作者原有的直接、克制、专业或个性化表达保持连续；
- 模板句、节奏和段落结构服务真实内容；
- 定义、功能、边界和结论采用目标结构；
- 否定表达只承载范围排除、法律义务、证据限制、辨析、纠错或真实反驳。

任一项存在偏差时，重新构建对应语义单元。

## Approval Gate

合同、政策、投标材料、公开声明、正式申请书和其他高风险外发文本中，修改超出本次授权，或需要新增、删除、改变事实主张、承诺、责任、资格、数字或引用时，先列出变化并获得用户确认。用户已经明确授权且材料足以支持的改写可直接完成，并在交付时列明实质变化；纯文字与格式修正直接完成。

## 输出边界

检测和编辑交付以下内容：

- 基于可观察文本的质量判断；
- 有位置和原文证据的具体发现；
- 与任务范围一致的修改；
- 事实依据支持的目标表达。

作者身份、所谓“人类概率”和“AI 含量”属于本 Skill 的评估范围之外。
